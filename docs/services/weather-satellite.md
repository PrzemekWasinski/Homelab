# Weather satellite ground station

Receives, Decodes and processes weather satellite signals using a cusotm C++ program.

## Setup

- Host Raspberry Pi 4 8GB
- Receiver: RTL-SDR Blog V4
- Antenna: V-Dipole tuned to 137.9MHz
- Recording & Decoding Software: SatDump
- Satellite Compatibility: Russina Meteor M2-3 and M2-4
